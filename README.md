# 키친포스

## 퀵 스타트

```sh
cd docker
docker compose -p kitchenpos up -d
```

## 요구 사항

### 상품

- 판매를 위한 기본 상품 정보를 나타낸다.
    - ex) 후라이드 16000원, 간장치킨 17000원
- 상품 등록
    - [ ] 상품은 이름과 가격을 필수로 가진다.
    - [ ] 상품의 가격은 0원 이상이어야 한다.
    - [ ] 상품 등록 시 이름의 유해성 여부를 검사한다.
- 가격 변경
    - [ ] 지정한 상품의 가격을 변경할 수 있다.
    - [ ] 가격 변경 후 메뉴에 포함된 상품들의 가격 총합이 메뉴의 가격보다 크면 숨김 처리한다.
- 상품 조회
    - [ ] 등록된 모든 상품의 목록을 조회한다.

### 메뉴

- 판매를 위한 단일 항목으로 고객에게 상품을 표시되는 단위가 된다.
    - ex) 후라이드치킨(메뉴)는 후라이드(상품)을 포함한다.
- 메뉴 등록
    - [ ] 메뉴의 가격은 0원 이상이어야 한다.
    - [ ] 메뉴 그룹을 지정해야 한다.
    - [ ] 등록된 상품 중 1개 이상을 포함해야 한다.
    - [ ] 메뉴의 가격은 지정한 상품들의 가격 총합보다 작아야 한다.
    - [ ] 메뉴의 이름은 유해성 여부를 검사한다.
- 가격 변경
    - [ ] 지정한 메뉴의 가격을 변경할 수 있다.
    - [ ] 가격은 0원 이상으로 변경할 수 있다.
    - [ ] 변경된 가격은 메뉴에 포함된 상품들의 총합보다 작아야 한다.
- 노출
    - [ ] 지정한 메뉴를 노출한다.
    - [ ] 메뉴의 가격이 메뉴에 포함된 상품들의 총합보다 작은 경우에만 노출처리할 수 있다.
- 숨김
    - [ ] 지정한 메뉴를 숨김처리한다.
- 메뉴 조회
    - [ ] 등록된 모든 메뉴를 조회한다.

### 메뉴 그룹

- 메뉴들을 분류하는 상위 그룹을 나타낸다.
    - ex) 후라이드치킨(메뉴), 양념치킨(메뉴)을 한마리메뉴(메뉴그룹)로 묶을 수 있다.
- 메뉴 그룹 등록
    - [ ] 메뉴 그룹은 이름을 필수로 가진다.
- 메뉴 그룹 조회
    - [ ] 등록된 모든 메뉴 그룹을 조회한다.

### 주문

- 고객의 주문을 나타낸다.
    - 주문 유형 : 배달(DELIVERY), 포장(TAKEOUT), 매장식사(EAT_IN)
    - 주문 상태 :
        - 대기(WAITING) : 주문이 등록됨
        - 수락(ACCEPTED) : 가게에서 주문을 수락함
        - 제공(SERVED) : 모든 메뉴 준비가 완료됨
        - 배달중(DELIVERING) : 고객에게 배달 중
        - 배달완료(DELIVERED) : 고객이 상품을 수령함
        - 완료(COMPLETED) : 주문이 완료됨
- 주문 생성
    - [ ] 주문 유형은 배달(DELIVERY), 포장(TAKEOUT), 매장식사(EAT_IN) 중 하나를 가져야 한다.
        - [ ] 주문 유형이 배달주문이면 배달주소를 입력해야한다.
    - [ ] 주문 유형이 매장식사인 경우 지정한 주문 테이블이 사용 중이어야 한다.
    - [ ] 주문 항목을 1개 이상 포함해야 한다.
    - [ ] 등록된 메뉴만 주문 항목에 포함될 수 있다.
    - [ ] 주문 유형이 배달이나 포장인 경우 주문한 메뉴의 수량은 반드시 1개 이상이어야 한다.
    - [ ] 노출 중이 아닌 메뉴는 주문할 수 없다.
    - [ ] 주문 요청의 가격과 메뉴의 가격이 일치해야 한다.
    - [ ] 생성한 주문은 대기 상태가 된다.
- 수락
    - [ ] 주문 상태를 수락(ACCEPTED)으로 변경한다.
    - [ ] 대기(WAITING)중인 주문만 변경할 수 있다.
    - [ ] 배달주문일 경우 배달요청을 보내야 한다.
        - [ ] 키친라이더 API를 호출해 주문 ID, 주문 금액, 배달 주소를 전달한다.
- 제공
    - [ ] 주문 상태를 제공(SERVED)으로 변경한다.
    - [ ] 수락(ACCEPTED)된 주문만 변경할 수 있다.
- 배달시작
    - [ ] 주문 상태를 배달중(DELIVERING)으로 변경한다.
    - [ ] 제공(SERVED)된 주문만 변경할 수 있다.
    - [ ] 주문 유형이 배달주문일 경우만 변경할 수 있다.
- 배달완료
    - [ ] 주문 상태를 배달완료(DELIVERED)로 변경한다.
    - [ ] 배달중(DELIVERING)인 주문만 변경할 수 있다.
- 완료
    - [ ] 주문 상태를 완료(COMPLETED)로 변경한다.
    - [ ] 주문 유형이 배달주문이면 배달완료(DELIVERED) 상태일 경우에만 변경할 수 있다.
    - [ ] 주문 유형이 포장주문, 매장식사인 경우 제공됨(SERVED) 상태일 때만 변경할 수 있다.
    - [ ] 주문 유형이 매장식사일 때 주문 테이블을 정리한다.
        - [ ] 해당 주문 테이블의 주문이 모두 완료 상태여야 한다.

### 주문 테이블

- 매장에서 주문을 받기 위한 테이블을 나타낸다. 이름, 손님 수, 사용 여부를 가진다.
- 주문 테이블 등록
    - [ ] 이름으로 주문 테이블을 생성한다.
    - [ ] 생성한 주문 테이블은 손님수 0명, 미사용 상태가 된다.
- 착석
    - [ ] 주문 테이블을 사용중으로 변경한다.
- 정리
    - [ ] 주문 테이블을 미사용으로 변경하고 손님수를 0명으로 설정한다.
    - [ ] 현재 주문 테이블의 모든 주문이 완료(COMPLETED)되면 정리할 수 있다.
- 손님수 변경
    - [ ] 손님 수는 0명 이상이어야 한다.
    - [ ] 미사용인 주문 테이블만 변경할 수 있다.
- 주문 테이블 조회
    - [ ] 모든 주문 테이블 목록을 조회한다.

## 모델링

### 상품 (`Product`)

* 프로퍼티
    * 이름 (`Name`)
        * 이름은 필수값이다.
        * 이름은 비속어를 포함하지 않아야 한다.
    * 가격 (`Price`)
        * 가격은 필수값이다.
        * 가격은 0원 이상이어야 한다.
* 유즈케이스
    * 상품을 추가한다.
    * 상품의 가격을 변경한다.
        * 해당 상품이 포함된 모든 메뉴의 가격이 메뉴 상품 목록(`Menu Products`)의 가격 총합보다 큰 경우 메뉴를 숨김 처리한다.
    * 상품의 목록을 조회한다.

### 메뉴 (`Menu`)

* 프로퍼티
    * 이름 (`Name`)
        * 이름은 필수값이다
        * 이름은 비속어를 포함하지 않아야 한다.
    * 가격 (`Price`)
        * 가격은 필수값이다.
        * 가격은 0 이상이다.
    * 메뉴 그룹 (`Menu Group`)
        * 메뉴 그룹은 필수값이다.
    * 노출 여부 (`Displayed`)
        * 노출 여부는 필수값이다.
        * 값은 노출(`true`), 숨김(`false`)이다.
    * 메뉴 상품 목록 (`Menu Products`)
        * 메뉴 상품 목록은 1개 이상의 메뉴 상품(`Menu Product`)을 가져야 한다.
* 유즈케이스
    * 메뉴를 추가한다.
        * 메뉴 가격은 포함된 메뉴 상품 가격의 총합 이하이어야 한다.
    * 메뉴를 노출한다.
        * 메뉴 가격은 포함된 메뉴 상품 가격의 총합 이하이어야 한다.
    * 메뉴를 숨긴다.
    * 모든 메뉴를 조회한다.

**메뉴 상품(`Menu Product`)**

* 프로퍼티
    * 상품 (`Product`)
        * 상품은 필수값이다.
    * 수량 (`Quantity`)
        * 수량은 필수값이다.

**메뉴 그룹(`Menu Group`)**

* 프로퍼티
    * 이름 (`Name`)
        * 이름은 필수값이다.
        * 이름은 비워 둘 수 없다.
* 유즈케이스
    * 메뉴 그룹을 등록한다.
    * 모든 메뉴 그룹의 목록을 조회한다.

### 주문 (`Order`)

**주문 테이블(`Order Table`)**

* 프로퍼티
    * 이름 (`Name`)
        * 이름은 필수값이다.
        * 이름은 비워 둘 수 없다.
        * 이름은 비속어를 포함하지 않아야 한다.
    * 고객의 수 (`Number of Customers`)
        * 고객의 수는 필수값이다.
        * 고객의 수는 0명 이상이다.
        * 기본값은 0이다.
    * 점유 여부 (`Occupied`)
        * 점유 여부는 필수값이다.
        * 사용(`true`), 미사용(`false`) 중 하나이다.
        * 기본값은 미사용이다.
* 유즈케이스
    * 주문 테이블을 등록한다.
    * 주문 테이블을 사용한다.
        * 미사용 주문 테이블만 사용할 수 있다.
    * 주문 테이블을 정리한다.
        * 모든 주문의 주문 상태가 완료이어야 한다.
        * 고객의 수를 0명으로 초기화한다.
        * 주문 테이블을 미사용으로 변경한다.
    * 고객의 수를 변경한다.
        * 주문 테이블이 사용 중이어야 한다.
    * 모든 주문 테이블의 목록을 조회한다.

**주문 항목 (`Order Line Item`)**

* 프로퍼티
    * 메뉴 (`Menu`)
        * 메뉴는 필수값이다.
        * 판매중인 메뉴만 주문항목에 추가해야 한다.
    * 가격 (`Price`)
        * 가격은 필수값이다.
        * 주문 항목의 가격은 메뉴의 가격과 동일해야 한다.
    * 수량 (`Quantity`)
        * 수량은 필수값이다.
        * 수량은 0개 이상이어야 한다.

**매장 주문(`Eat In Order`)**

* 프로퍼티
    * 주문 유형 (`Order Type`)
        * 주문 유형은 필수값이다.
    * 주문 상태 (`Order Status`)
        * 주문 상태는 필수값이다.
        * 기본값은 대기이다.
        * 매장 주문은 대기, 수락, 제공, 완료 순서로 진행된다.
    * 주문 항목 목록 (`Order Line Items`)
    * 주문 일시 (`Order DateTime`)
        * 주문 일시는 필수값이다.
    * 주문 테이블 (`Order Table`)
        * 주문 테이블은 필수값이다.
* 유즈케이스
    * 매장에서 메뉴를 주문한다.
    * 메뉴 주문을 수락한다.
        * 대기인 주문만 수락할 수 있다.
    * 주문받은 음식을 완성하여 주문 테이블에 제공한다.
        * 수락된 주문만 제공할 수 있다.
    * 매장 주문을 완료한다.
        * 제공된 주문만 완료할 수 있다.
        * 주문 테이블을 정리해야 한다.

**포장 주문(`Take Out Order`)**

* 프로퍼티
    * 주문 유형 (`Order Type`)
        * 주문 유형은 필수값이다.
    * 주문 상태 (`Order Status`)
        * 주문 상태는 필수값이다.
        * 기본값은 대기이다.
        * 매장 주문은 대기, 수락, 제공, 완료 순서로 진행된다.
    * 주문 항목 목록 (`Order Line Items`)
        * 적어도 한 개의 주문 항목을 가져야 한다.
    * 주문 일시 (`Order DateTime`)
        * 주문 일시는 필수값이다.
* 유즈케이스
    * 포장으로 메뉴를 주문한다.
    * 포장 주문을 수락한다.
        * 대기인 주문만 수락할 수 있다.
    * 고객이 주문한 음식을 완성하여 고객에게 제공한다.
        * 수락된 주문만 제공할 수 있다.
    * 포장 주문을 완료한다.
        * 제공된 주문만 완료할 수 있다.

**배달 주문(`Delivery Order`)**

* 프로퍼티
    * 주문 유형 (`Order Type`)
        * 주문 유형은 필수값이다.
    * 주문 상태 (`Order Status`)
        * 주문 상태는 필수값이다.
        * 기본값은 대기이다.
        * 매장 주문은 대기, 수락, 제공, 배달 중, 배달 완료, 완료 순서로 진행된다.
    * 주문 항목 목록 (`Order Line Items`)
        * 적어도 한 개의 주문 항목을 가져야 한다.
    * 주문 일시 (`Order DateTime`)
        * 주문 일시는 필수값이다.
    * 배달 주소 (`Delivery Address`)
        * 배달 주소는 필수값이다.
* 유즈케이스
    * 배달로 메뉴를 주문한다.
    * 배달 주문을 수락한다.
        * 배달 대행사에 배달을 요청해야 한다.
        * 대기인 주문만 수락할 수 있다.
        * 주문 상태를 수락으로 변경한다.
    * 고객이 주문한 음식을 완성하여 라이더에게 제공한다.
        * 수락된 주문만 제공할 수 있다.
        * 주문 상태를 제공으로 변경한다.
    * 라이더가 메뉴를 배달한다.
        * 제공된 주문만 배달할 수 있다.
        * 주문 상태를 배달 중으로 변경한다.
    * 라이더는 고객에게 메뉴를 전달한다.
        * 배달 중인 주문만 배달 완료할 수 있다.
        * 주문 상태를 배달 완료로 변경한다.
    * 배달 주문을 완료한다.
        * 배달 완료인 주문만 완료할 수 있다.
        * 주문 상태를 완료로 변경한다.
